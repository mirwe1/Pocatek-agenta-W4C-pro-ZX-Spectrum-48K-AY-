# Pocatek-agenta-W4C-pro-ZX-Spectrum-48K-AY-
Text/Graphics adventure for ZX Spectrum in CZ language
Takže se povedlo najít více podkladů k Počátku agenta W4C, k té "nudné a prázdné" textovce, jak zněla, dlužno říci, oprávněná recenze. Pro mne to ale je srdcovka, neboť je to první hra (a na dlouhou dobu poslední, kterou jsme tehdy delali s Bernym společně). Verze pro Spectrum se definitivě ztratila, zustalo par necitelnych basicových výpisů, jedna mapa na ctvereckovaném papíře a nejaka komunikace s Bernym. K dokonceni z fragmentů pomohl jako vždy Codex a Python a hafo všelijakých konvetorů.
